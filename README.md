# Spanska – övningar

Interaktiva övningar i spanska, en mapp per vecka. Öppna `index.html` för att se alla veckor.

| Vecka | Moment | Mapp |
| --- | --- | --- |
| 45 | Pågående form: böja ESTAR och välja rätt ändelse (-ando / -iendo) | `v45-pagaende-form/` |

## Dela som webbsida

Slå på GitHub Pages under **Settings → Pages**: välj grenen `main` och mappen `/ (root)`. Adressen till sidan visas sedan överst på samma inställningssida.
